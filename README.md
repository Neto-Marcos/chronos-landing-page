# Chronos — Landing Page

Landing page comercial do Chronos, uma plataforma de gestão de jornada com reconhecimento facial, banco de horas e operação multiempresa.

## Demonstração

- Site: https://chronos-site-tau.vercel.app/
- Painel: https://admin-panel-production-7c1d.up.railway.app/

## Recursos da landing page

- Página inicial responsiva e acessível (identidade visual Dark & Gold)
- Vitrine **"Por dentro da plataforma"** com capturas reais anonimizadas do painel administrativo
- Apresentação de funcionalidades (reconhecimento facial em 3 poses, quiosque offline, NSR com assinatura encadeada, ponto móvel, banco de horas automático, central de pendências e WhatsApp)
- Planos, condições comerciais e perguntas frequentes
- Formulário comercial integrado ao WhatsApp com proteção anti-spam
- Páginas completas de Política de Privacidade, Termos de Uso e Dados Biométricos (LGPD)
- `sitemap.xml`, `robots.txt` e metadados Open Graph / Schema.org (`SoftwareApplication`)

## Tecnologias

Build estático otimizado com Vite + TypeScript + CSS3 (fontes auto-hospedadas `Archivo`, `DM Sans` e `IBM Plex Mono`).

## Desenvolvimento local

Sirva a pasta com qualquer servidor HTTP estático:

```bash
npx serve .
```
