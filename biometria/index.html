Como tratamos os dados faciais

Documento em elaboração — pendente de revisão jurídica. Esta página explica as práticas atuais do produto em linguagem acessível, mas não constitui o texto final nem parecer jurídico. Não publicar sem revisão profissional.

O registro de ponto por reconhecimento facial usa dados biométricos — uma categoria de dado pessoal sensível segundo a LGPD. Esta página explica, em linguagem simples, o que é coletado, para que serve e como é protegido.

O que é coletado

  • Imagens de cadastro — três fotos do rosto (frontal, lateral esquerda e lateral direita), enviadas pelo administrador ou RH da empresa no cadastro do colaborador.
  • Referências faciais — a partir das imagens de cadastro, o sistema gera representações matemáticas do rosto (uma por pose), usadas nas comparações. Não são fotos: são vetores numéricos que não permitem reconstruir a imagem original.
  • Fotos de marcação — a foto capturada pelo tablet no momento de cada registro de ponto, guardada como comprovação da marcação.

Para que os dados servem

Exclusivamente para identificar o colaborador no momento do registro de ponto e comprovar as marcações. Os dados faciais não são usados para outras finalidades, não são vendidos e não são compartilhados entre empresas clientes.

Como os dados são protegidos

  • Isolamento por empresa: os dados faciais de uma empresa nunca são comparados com os de outra;
  • Acesso restrito por níveis de permissão dentro da própria empresa;
  • Comunicação protegida entre tablet, painel e servidor;
  • Tablets autorizados individualmente, com credencial revogável.

Retenção e exclusão

As referências faciais existem enquanto o colaborador estiver cadastrado. [Pendente de revisão jurídica: prazos formais de retenção das imagens e procedimento de exclusão após o desligamento, considerando as obrigações legais de guarda de registros de jornada.]
