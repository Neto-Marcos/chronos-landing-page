# Chronos — Landing Page

Landing page comercial do Chronos, uma plataforma de gestão de jornada com reconhecimento facial, banco de horas e operação multiempresa.

## Demonstração

- Site: https://chronos-site-tau.vercel.app/
- Painel: https://admin-panel-production-7c1d.up.railway.app/

## Recursos da landing page

- Página inicial responsiva e acessível
- Apresentação de funcionalidades e fluxo do produto
- Planos e perguntas frequentes
- Formulário comercial integrado ao WhatsApp
- Páginas de privacidade, termos e dados biométricos
- Metadados para SEO e compartilhamento social

## Tecnologias

HTML5, CSS3 e JavaScript ES Modules. O projeto não exige etapa de build.

## Desenvolvimento local

Sirva a pasta com qualquer servidor HTTP estático. Por exemplo:

```bash
npx serve .
```

## Publicação

O projeto está preparado para hospedagem estática na Vercel.

## Status

O Chronos está em desenvolvimento. As páginas legais deixam isso explícito e deverão ser revisadas antes de uma operação comercial.
